Xongyi 主题 v1.0 正式发布了！这是一款专为**机构官网**打造的 Hexo 通用主题。

## 核心特性

- **三套预设布局**：企业（enterprise）、政务（government）、教育（education）一键切换配色与默认板块组合
- **12 个首页板块**：横幅、快捷入口、数据统计、核心业务、关于我们、产品案例、新闻动态、团队、合作伙伴、风采图库、行动条、联系我们，全部支持启用/关闭与自由排序
- **丰富设置项**：导航、页脚、社交链接、备案信息、SEO、统计分析等 60+ 配置项
- **一键部署**：源码托管 GitHub 后，可直接部署到 GitHub Pages、Cloudflare Pages、腾讯 EdgeOne Pages、Vercel、Netlify

## 快速开始

```bash
npm install
npm run server   # 本地预览 http://localhost:4000
npm run build    # 生成静态文件到 public/
```
